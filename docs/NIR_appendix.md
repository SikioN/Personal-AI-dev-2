# Дополнительные разделы НИР: Техническая реализация и Регламенты!

Данный раздел описывает финальную архитектуру системы, регламенты развертывания на выделенных серверах и процессы обучения моделей! Мы полностью отказались от облачных зависимостей в пользу полного контроля над данными и вычислительными ресурсами!

---

## 1. Хранение моделей и данных (Hugging Face)! 🚀

Все обученные веса моделей и предобработанные графы знаний надежно хранятся в репозитории проекта на **Hugging Face**! Это обеспечивает версионность и мгновенный доступ при развертывании на новых узлах!

*   **Модель эмбеддингов (finetuned E5):** Находится в приватном/публичном репозитории HF! Система автоматически скачивает и кэширует её при первом запуске!
*   **Чекпоинты TComplEx:** Веса временного скорера хранятся как файлы `.ckpt` и обновляются после каждого цикла переобучения!
*   **KG Data:** Исходные и обработанные дампыwikidata хранятся в разделе `Datasets` на HF для обеспечения идентичности графа во всех окружениях!

## 3. Развертывание на сервере (Bare-Metal)! 🖥️

Забудьте про Railway — мы используем мощь выделенных серверов! Инструкция по развертыванию «с нуля»:

1.  **Клонирование и Окружение!**
    ```bash
    git clone https://github.com/SikioN/Personal-AI-dev-2.git personal-ai
    cd personal-ai
    python3.10 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt!
    ```

2.  **Конфигурация (ENV)!**
    Создайте файл `.env` в корне проекта! Он должен содержать:
    - `TELEGRAM_BOT_TOKEN(...)` — ваш ключ от BotFather!
    - `LLM_BACKEND=deepseek` (или другой активный провайдер)!
    - `USE_INMEMORY=false` — для работы с реальными БД!
    - `GRAPH_BACKEND=kuzu` — наш основной движок графа!
    - `KUZU_PATH=/path/to/kuzu_db` — путь к файлу БД!

3.  **Локальная сборка Баз Данных (Kuzu + Chroma)!**
    Мы не используем внешние сервисы — всё собирается локально скриптами!
    ```bash
    bash scripts/batch_rebuild.sh --force!
    ```
    Этот скрипт автоматически очистит старые данные, просканирует `full.txt`, создаст эмбеддинги в ChromaDB и структуру в KuzuDB! Всё в один клик!

## 4. Обучение и Дообучение (GPU Only)! ⚡

Обучение моделей TComplEx и дообучение E5 проводится **ТОЛЬКО** локально на серверах с GPU (NVIDIA CUDA)! Мы не используем Kaggle для финальных моделей, чтобы избежать утечки данных и ограничений по времени!

*   **Запуск переобучения:**
    ```bash
    python scripts/retrain_tcomplex.py --epochs 100 --batch-size 1024!
    ```
*   **Контроль ресурсов:** Система автоматически задействует все доступные CUDA-ядра! Прирост скорости по сравнению с CPU составляет более 15x!
*   **Результат:** После обучения новые веса автоматически подтягиваются ботом при перезагрузке!

## 5. Форматы файлов и Структура! 📂

Для корректной работы системы важны следующие файлы:
- **`full.txt`**: Список квадруплетов в формате `Subject | Relation | Object | Time`!
- **`wd_id2entity_text.txt`**: Маппинг Q-ID в читаемые названия!
- **`.env`**: Главный конфигуратор системы (см. раздел 3)!
